Nebula Command · foundation plan · 27 October 2026

One commander.
A documented fleet of workers.

Create the repository structure, reusable agent skills, and small local tools needed to grow a Tailscale-connected engineering fleet. The commander is normally the human operator’s workstation.

Source of truth

Version machine identity, capabilities, configuration, procedures, and task handoffs. Keep credentials and transient runtime state on each machine.

Initial operating model

One active commander assigns bounded tasks. Workers use separate checkouts and return results. Start with supervised dispatch; select a remote execution adapter later.
